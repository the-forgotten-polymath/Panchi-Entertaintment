# 🏛️ Panchi Entertainment — Luxury Wedding & Celebrity Management Web Portal

A high-end, responsive digital platform for **Panchi Entertainment**, managing high-profile Indian weddings, celebrity artist bookings (*Diljit Dosanjh, AP Dhillon, Karan Aujla, B Praak*), bespoke Punjabi catering, luxury hospitality, and specialized event productions.

---

## 🌟 Overview & Highlights

- **Complete 33-Page Architecture:** Full coverage of master pages, 13 dedicated wedding sub-ceremony showcases, and 8 celebrity artist booking funnels.
- **Ultra-Responsive Layout:** Fine-tuned for mobile (320px–430px), tablet, and 4K desktop screens with zero horizontal overflow.
- **Cinematic Media Integration:** 248 high-resolution images, 35 MP4 video showreels, and interactive visual showcases.
- **SEO & Googlebot Ready:** Clean semantic HTML structure, open-graph metadata, and XML sitemap architecture ready for Google indexing.
- **Direct Conversion Touchpoints:** Interactive WhatsApp lead routing with pre-configured event and artist booking parameters.

## 🛠️ Tech Stack & Assets

- **Frontend:** Semantic HTML5, Vanilla CSS3 (Custom Luxury Design Tokens), Modular ES6 JavaScript
- **Typography:** *Outfit*, *Plus Jakarta Sans*, *Playfair Display*
- **Icons:** FontAwesome 6.5 Pro Icons
- **Media Assets:**
  - 248 Optimized Photographs (`assets/img/`)
  - 35 Showreel & Video Backgrounds (`assets/img/`)
  - 4 CSS Stylesheets (`assets/css/`)
  - 3 JavaScript Controllers (`assets/js/`)

---

## 🚀 Running Locally

You can run the portal locally using any standard static file server:

```bash
# Using Python
python3 -m http.server 8080

# Or using npx serve
npx serve .
```

Open `http://localhost:8080` in your web browser.
